# F_Downloader

一个支持单线程 / 多线程的下载工具，基于 Qt 6 + C++17 开发。

## ✨ 功能

### 下载
- **单线程下载**：标准 HTTP 下载
- **多线程下载**：基于 HTTP Range 分段并发，线程数可自选（1-128）
- **断点恢复**：暂停/停止后可继续，从已下载位置接着下
- **文件信息检测**：自动获取文件大小、判断服务器是否支持分段

### 状态与进度
- 实时进度条（千分比精度）
- 实时速度显示（每 500ms 刷新）
- 下载完成 / 失败 / 中止的明确状态提示

### 健壮性
- **HTTP 206 校验**：多线程时校验服务器是否真按分段返回
- **429 限流保护**：服务器限流时自动中止并提示
- **30 秒传输超时**：单个连接卡死不拖累整体
- **完成时文件大小核对**：防止静默丢字节

### 体验
- **路径自动补全**：输入目录自动从 URL 取文件名；无后缀自动补
- **退出保护**：下载中关闭窗口会确认，退出时清理未完成文件
- **窗口自适应布局**

## 🔧 实现要点

### 多线程分段

每个分段用独立的 `QFile` 句柄写入同一文件的不同偏移位置，避免多线程竞争文件游标。

```cpp
struct chunk {
    qint64 start;        // 分段起始字节
    qint64 end;          // 分段结束字节（含）
    qint64 receive;      // 已接收字节数（恢复依据）
    QNetworkReply *reply;
    QFile *file;
};
```

最后一段终点必须是 `total - 1`，否则除不尽时会丢字节。

### 断点恢复
- 单线程：记录 `QFile::pos()`，恢复时用 `Range: bytes=<pos>-`
- 多线程：每个 chunk 记录 `receive`，恢复时用 `Range: bytes=<start+receive>-<end>`

恢复时必须用 `ReadWrite` 打开文件，`WriteOnly` 会清空已下载内容。

### 暂停 / 停止 / 退出

`abort()` 固定产生 `OperationCanceledError`，靠三个标记区分用户意图：

| 标记 | 行为 |
| --- | --- |
| `m_pause` | 保留进度，等继续 |
| `m_stop` | 删除不完整文件，清理状态 |
| `m_quitting` | 交由 `closeEvent` 统一清理 |
